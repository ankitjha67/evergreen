## Rules applied
### stripe-basil-001 - Upcoming invoice endpoints replaced by Create Preview Invoice [breaking]
The Retrieve Upcoming Invoice (invoices.retrieveUpcoming) and List Upcoming Invoice Line Items (invoices.listUpcomingLines) endpoints were removed in API version 2025-03-31.basil. They are replaced by the Create Preview Invoice endpoint (invoices.createPreview), which returns the same preview invoice object; its line items are paginated via invoices.listLineItems on the returned preview, or read from preview.lines.
**Before:**
```
const upcoming = await stripe.invoices.retrieveUpcoming({ customer: customerId });
```
**After:**
```
const upcoming = await stripe.invoices.createPreview({ customer: customerId });
```
Docs: https://docs.stripe.com/api/invoices/create_preview

### stripe-basil-002 - Subscription current_period_start/end moved to subscription items [breaking]
In 2025-03-31.basil, the current_period_start and current_period_end fields were removed from the Subscription object. Billing periods are now tracked per subscription item: subscription.items.data[i].current_period_start / current_period_end. For single-item subscriptions, use the first item's period fields.
**Before:**
```
const renewsAt = subscription.current_period_end;
```
**After:**
```
const renewsAt = subscription.items.data[0].current_period_end;
```
Docs: https://docs.stripe.com/changelog/basil#subscriptions
